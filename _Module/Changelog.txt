AOR v1.5.7.0 :
- Added support for game version 1.5.7. Game versions 1.4.8 and 1.4.7 are still supported.
	Version numbers now follow the game version: v1.5.7.0 is the update after v1.6.5.
- Mod Configuration Menu is now optional. Without it, change the settings in Modules\ArenaOverhaulRedux\ModConfiguration.xml.
	The settings of single heroes (loadout options and weapon priorities) still need Mod Configuration Menu.
	Without it every clan hero uses the "Default Arena Practice settings for heroes" and no weapon priorities.
- Added translations for 12 languages.
- Removed the "Loaded Arena Overhaul!" message at game start.
- Fixed "{GOLD ICON}" showing as text instead of the gold icon.
- Fixed typos and outdated default values in several texts and setting descriptions.
